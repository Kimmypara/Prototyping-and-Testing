# Test plan: Notification System (file, assignment & grade)

## Persona
People who have new activity on My Units

## Scenario
You are a student and when you are logged in, you should see any new activity 

## Tasks
1. Check for new activities 
2. Identify which unit has a new update.
3. Download the brief 
4. Submit the assignment ( and then the teacher will grade you)
5. Check the results 
## Success Metric
4/5 users identify any new activity quickly 

## Expected Outcome
Allow users to notice immediately new activities, download a file, submit an assignment and view grades
